Metaflow Framework — Master Reference Index & Attribute Dictionary (v1.3.0)

Authoritative Source of Truth: Single comprehensive lookup dictionary indexing every configuration attribute, CDC strategy, target type, technical concept, and framework-generated column across the NextGen Metadata Framework.

1. Top-Level Spec Schema

The root structure of an onboarding JSON/YAML specification file:

Attribute Type Required Default Description
dataflow_group_id string Yes — Unique identifier for this pipeline group. All control-table rows in this spec are upserted under this ID.
pipeline_parameters object No {} String to value map substituted into ${param} placeholders in transformation_sql, filter_condition and transform_sql. Strings are single-quoted automatically.
spark_config object No {} Group-scoped Spark configuration. Keys must start with spark.; values may be string, number or boolean. Pipeline and runtime values strictly override framework defaults.
ingestion_flows array At least 1 flow array non-empty [] Bronze-layer ingestion definitions.
transformation_flows array At least 1 flow array non-empty [] Silver/Gold transformation definitions.
reconciliation_flows array At least 1 flow array non-empty [] Cross-dataset comparison and self-healing definitions.
observability array No [] Telemetry export destinations (Volume & OTLP). Does not count toward the non-empty flow requirement.

2. Ingestion Flow Schema

Attributes inside ingestion_flows[]:

Attribute Type Required Default Description
dataflow_id string Yes — Unique flow identifier. Referenced by transformation flows as upstream dependency.
source_system string No — Descriptive metadata stored in control tables.
source_database string No — Descriptive landing database name.
source_table_name string No — Descriptive source table name.
source_description string No — Becomes the target Delta table's COMMENT. Supports {{catalog}} and {{env}}.
source_type string Yes autoloader Ingestion reader engine: autoloader, zerobus, or asn1.
target_catalog string Yes {{catalog}} Unity Catalog catalog name for the target table.
target_schema string Yes — Schema / database for the target table.
target_table string Yes — Target Delta table name.
target_type string Yes streaming_table streaming_table, materialized_view, batch_table, external_sink, or sink.

3. Source Config Reference

Common and specific attributes inside source_config:

Attribute Type Required Description
source_config.path string Yes (Auto Loader/ASN.1) Landing directory in Unity Catalog Volume monitored for new incoming files.
source_config.format string Yes (Auto Loader) File format: csv, json, parquet, avro, text, orc, binaryFile.
source_config.schema_location string No Auto Loader schema inference and evolution checkpoint directory.
source_config.capture_technical_metadata boolean No (default true) Captures __framework_source_file_name, _size, _modification_time, _metadata_headers and gates __framework_ingestion_timestamp_utc.
source_config.remove_dups boolean No (default false) Full-row dropDuplicates over non-framework columns. When streaming, bound with dedup_watermark.

4. Auto Loader Source

Auto Loader monitors a Unity Catalog Volume landing directory for incremental file ingestion.

5. Zerobus Source

Zerobus provides streaming ingestion from an existing Delta table using source_catalog, source_schema, source_table, starting_version, and max_bytes_per_trigger.

6. ASN.1 Source

ASN.1 decodes binary BER/DER telecom Call Detail Records (CDRs) using asn1_schema_path, asn1_codec (ber/der), and asn1_pdu_name.

7. Source ZIP Handling

Extracts and optionally PGP-decrypts password-protected ZIP archives at rest before ingestion.

8. Target Config & Load Strategies

target_config.cdc_load_strategy controls data loading and merging into target tables:

Strategy Type Required Parameters Description
APPEND Append-only None Immutable facts, events, and logs. High-performance append without merge diff.
TRUNCATE_AND_LOAD Full replace None Full extract each run. Small lookup tables recomputed entirely.
SCD1 Overwrite current primary_keys Entity state where only the latest attribute values matter.
SCD2 Full history primary_keys Track full history with effective/expiration timestamp intervals and active flags.
SCD3 Current + Previous primary_keys, columns_to_check Transformation flows only. Stores current value and previous value in dedicated columns.
FULL_SNAPSHOT_CDC_NO_PK Snapshot diff generate_surrogate_key: true Diffs full snapshot extracts using a framework-generated surrogate key.

9. Column-Level AES-GCM Encryption

target_config.encrypted_columns[] encrypts sensitive PII columns in place using AES-GCM with keys fetched securely from Unity Catalog secrets.

10. Sinks & Egress

When target_type is sink or external_sink, exports data to external storage, Kafka, or PGP-encrypted ZIP archives.

11. Data Quality & Quarantine

Data quality rules with actions warn, drop, fail, or quarantine (routes non-compliant rows to a quarantine table).

12. Governance & Tags

Applies Unity Catalog column tags (e.g. mask: PII) and table tags (e.g. row_filter: region) post-deployment via ALTER TABLE.

13. Transformation Flows

Silver and Gold transformations with flow_step_id, dataflow_id, transformation_sql, and source_inputs[].

14. Source Inputs & Watermarks

Declares upstream tables. Supports stream-stream joins with watermark.event_time_column and watermark.delay_threshold.

15. Column-Level Decryption

source_inputs[].decrypted_columns[] decodes AES-GCM encrypted columns before transformation_sql runs.

16. Reconciliation Flows

Automated two-tier verification (Phase 1 bit_xor hash fingerprint + Phase 2 full join) and self-healing.

17. Reconciliation Datasets

Source dataset baseline definition supporting filter conditions and data standardization expressions.

18. Reconciliation Targets & Healing

Target table comparison with comparison_direction (both, source_to_target, target_to_source) and append_target_table for self-healing.

19. Observability & Telemetry

Telemetry export to Unity Catalog Volumes (DATABRICKS_VOLUME) or OpenTelemetry collectors (OTLP_CONSUMER) in triggered or continuous mode.

20. Template Variables

{{catalog}} and {{env}} resolve before parsing. ${param} substitutes at execution time inside SQL expressions.

21. Framework-Generated Columns

Standardized lineage and audit columns: __framework_ingestion_timestamp_utc, __framework_source_file_name, __framework_hash_key, __framework_hash_value, __framework_surrogate_key, __framework_dq_failed_rule_ids, __framework_pipeline_run_id, etc.
